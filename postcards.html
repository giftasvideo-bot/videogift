💌 Postcard Print Layout

🖨️ Print Postcards

Pick a postcard design below (Love, Graduation, Birthday), then select the card IDs to print. Each postcard is two A4-landscape sheets: the front cover artwork, then the inside artwork with that card's QR code added in the blank area next to the message. All cards in one print/PDF job use the currently selected design — switch designs and print again for a different batch.

Sending to a print shop? Use "⬇️ Download Print PDF" — it builds an actual PDF with fixed A4 pages and full-resolution artwork baked in, so the layout can't be thrown off by anyone's local print settings. The "🖨️ Print" button is fine for a quick office/home test print instead. Note: the PDF is generated in RGB, not CMYK — check with your print shop if they specifically require CMYK files.
